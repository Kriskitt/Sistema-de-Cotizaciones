# Sistema de Cotizaciones

Aplicación web para gestionar y solicitar cotizaciones. Incluye acceso por roles de administrador, vendedor y cliente, paneles de métricas, listado y detalle de cotizaciones, gestión de usuarios y un flujo interactivo para armar cotizaciones con productos, cantidades, descuentos, IGV y vista previa.

## Tecnologías

- Angular 21
- TypeScript
- Node.js
- npm
- Bootstrap 5
- Bootstrap Icons

Nota de migración: la aplicación fue migrada desde una versión estática en HTML, CSS y JavaScript a una aplicación Angular con componentes standalone, Angular Router, servicios, Signals y formularios reactivos.

## Requisitos

- Node.js v23.11.0
- npm

Angular 21 muestra advertencias de compatibilidad porque Node.js v23.11.0 es una versión impar no LTS y no pertenece al rango oficial soportado por Angular. Se mantuvo esta versión de Node.js porque es el entorno requerido para el proyecto.
